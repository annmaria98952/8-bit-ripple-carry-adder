# 8-Bit Ripple Carry Adder — CMOS Design

## Overview
Designed and simulated an 8-bit ripple carry adder using CMOS full-adder circuits in Cadence Virtuoso. Two logic implementations were explored: a NAND-only design and a design using XOR, AND, and OR gates.

## Objectives
- Design CMOS full-adder circuits using two different logic styles.
- Cascade eight full-adder stages to implement an 8-bit ripple carry adder.
- Verify sum and carry outputs through circuit simulation.
- Compare the logic complexity of the two implementations.

## Tools Used
- Cadence Virtuoso
- CMOS circuit design and simulation

## Design Implementations

### 1. NAND-Only Logic
Implemented the full-adder logic using NAND gates to explore an alternative CMOS logic realization.

### 2. XOR/AND/OR Logic
Implemented the full-adder logic using XOR, AND, and OR gates to generate the sum and carry outputs.

## Verification
Transient simulations were used to examine the sum outputs and carry propagation across the cascaded full-adder stages.

## Key Learning Outcomes
- CMOS implementation of combinational logic
- Full-adder design and cascading
- Carry propagation in multi-bit arithmetic circuits
- Schematic design and simulation using Cadence Virtuoso
